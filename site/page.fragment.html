Onchain liquidity on Monad

Every 15-minute market gets a price. From the first second.

Converge is a vault that makes two-sided markets in short UP/DOWN rounds, so a new market never opens to an empty book. Liquidity providers deposit once. Traders bet with a passkey: no seed phrase, no extension.

The problem

Short markets die when the pool is empty.

Earlier betting apps on Monad faded because nobody wanted to be the first liquidity in a market that lasts fifteen minutes. A market maker has to quote every block, narrow as expiry nears, and pull quotes when the price jumps. On most chains that costs more than it earns. On Monad a full re-quote costs about a fifth of a cent.

How it works

Four parts, each one checkable.

1 · Account

A passkey is the wallet

Mera turns a Face ID or fingerprint passkey into the account. The key exists only for one confirmation, then it is wiped.

2 · Bet

Priced one second ahead

An order fills two seconds after it is placed, at the oracle price for that second. Nobody trades against a price they could already see move.

3 · Liquidity

One vault quotes every round

Depositors share the spread. Loss limits are 1% per market and 8% in total, and a circuit breaker stops quoting without ever blocking an exit.

4 · Settlement

Chainlink decides

A CRE workflow creates, opens and resolves each round from a signed price report. A fallback keeper does the same if the network is down.

We backtested our first design and it lost.

Keeper-posted quotes were beaten by faster traders, so the backtest verdict was "unprofitable as specified". That is why orders are forward-priced. The vault and the venue were rebuilt around the result (decision record ADR-004).

Live on testnet

Kuru: a new asset class on the book

Each round's UP token is a collateralised binary outcome that converges to 0 or 1. We list it as its own Kuru market, seed it and quote both sides around the vault's fair value.

  • One full round: market created, 18 two-sided quotes, torn down and redeemed.
  • A separate wallet bought 2.2 UP for $2.00 and sold it back for $1.82: the cost is the quoted spread.
  • The market page shows Kuru's bid and ask next to the vault's price.

Deploying

Envio: the read side of the product

HyperIndex serves positions and realised PnL, vault value and APY history, and protocol stats. The chain stays the fallback and is the source for exits.

  • Handlers for markets, trades, positions, vault NAV and partners, with 100 passing tests.
  • Reconcile tool compares indexed rows with the chain at the indexer's own block.
  • Hosted build on Envio Cloud is in progress; a local run indexed the live testnet deployment.

Built and tested

Mera: the whole account layer

No seed phrase, no extension, no custody backend. Sign in with a passkey, get test money, bet in one tap and one confirmation, collect in one tap.

  • The exported recovery phrase gives the same address in MetaMask or Rabby.
  • The build fails if any other wallet SDK is added.
  • End-to-end tests run the real passkey flow in a browser with a virtual authenticator.

Simulated, not deployed

Chainlink CRE: orchestration

The scheduler workflow reads the live factory, plans create, open and resolve actions, fetches Data Streams evidence and writes one report to the receiver contract.

  • Ran in the official CRE simulator against live Monad testnet: 2 chain reads, 8 planned actions.
  • That run was a dry run, so it sent no transaction. Deployment needs CRE Early Access.
  • Testnet uses a signed test report; Data Streams has not run on mainnet yet.

What this is not yet

  • It runs on testnet. The Kuru maker is our own wallet, so the book proves the pipeline, not organic demand.
  • The code is reviewed internally and by an adversarial pass, not externally audited. The mainnet cap is set at 5,000 USDC.
  • Chainlink Data Streams has never run on a real report, and its lead over exchange prices is unmeasured. That is the one high-severity item still open.
  • Mainnet needs a multisig, Data Streams credentials and an audit decision. The deploy tooling, runbook and canary were rehearsed on a mainnet fork.
