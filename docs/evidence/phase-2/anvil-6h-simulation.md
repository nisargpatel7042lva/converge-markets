# Phase 2: 6-hour anvil simulation

Generated by `services/scheduler/fallback/test/integration/sixHours.test.ts` (`make check-2`).
Chain time advanced in 10s steps (the production loop interval); the fallback scheduler
ran one tick per step as leader, reading state through SchedulerLens (one call). MON (1h only,
ADR-002) resolves via round proofs over a mock aggregator whose update gaps are jittered 20-90 s
(as observed on Monad mainnet); BTC/ETH resolve via Data Streams-shaped reports from the TEST
signer (MockStreamsVerifierProxy, 20 s finalization window). Happy path otherwise: no RPC faults
(the outage case is in recovery.test.ts).
